# bsf_precipitation_access_scripts
QGIS scripts for automated precipitation map generation using CMIP6 climate data.

# Automated Precipitation Mapping Scripts for Climate Change Scenarios

This repository contains Python scripts designed for QGIS to automate the processing and visualization of precipitation data under future climate scenarios. The scripts are tailored for use with CMIP6 projections and facilitate the generation of thematic maps for climate impact assessment in Brazil.

## Description

These tools allow users to:

- Apply consistent styling to precipitation raster layers
- Generate monthly maps for different Shared Socioeconomic Pathways (SSP126, SSP245, SSP370, SSP585)
- Automate layout generation and export as PNG or PDF
- Reclassify raster values based on risk thresholds
- Calculate basic statistics and create summary tables
- Support decision-making in agriculture and environmental planning

## Requirements

- QGIS 3.28 or higher
- Python 3.9+
- Installed QGIS Processing Toolbox and access to raster climate layers (e.g., from WorldClim or downscaled CMIP6 datasets)
